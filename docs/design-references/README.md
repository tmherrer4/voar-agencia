# Design references

These files are visual guidance for VOAR VIAGENS. They are not production
assets, application fixtures, or sources of verified commercial content.

- `itinerary-proposal-reference.html`: layout, interaction, spacing, and
  luxury-editorial direction for a client-facing itinerary proposal. Ignore the
  sample AURA brand, inline scripts, CDN dependencies, and mock data.
- `hotel-selection-reference.jpeg`: VOAR VIAGENS hotel-selection presentation
  reference.

Use the references to inform semantic design tokens and shadcn-based React
components. Do not import or execute the HTML in the application.
