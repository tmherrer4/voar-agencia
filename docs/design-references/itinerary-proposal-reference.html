Arquitetura de Dados & Instruções

Este protótipo foi construído segundo os princípios de desacoplamento da SKILL 10 Travel Proposal Designer.

// 1. Separação Estrita de Responsabilidades:

O arquivo HTML consome o objeto global JS `TRAVEL_PROPOSAL_DATA` contendo todos os trechos, hotéis, fotos do Unsplash e precificação DEMO.

// 2. Como Rodar Localmente:

Basta salvar o código como `index.html` e abrir diretamente em qualquer navegador moderno (Chrome, Safari, Edge, Firefox) sem dependência de build steps ou node server.

// 3. Integração com Backend/API:

Em ambiente de produção, o backend (Python/Node/LLM) deve injetar o JSON estruturado diretamente na const `TRAVEL_PROPOSAL_DATA` para re-renderizar a proposta instantaneamente.
